### M5Stackとミニリレーユニットを使ったコイル制御テスト

EFNMR（地球磁場NMR）量子コンピュータのハードウェア制御において、要となるのが「分極」と「受信」のタイミング切り替えです。今回は、M5Stack CoreS3 LiteとM5Stack用ミニリレーユニットを用いて、プロトン（精製水）を分極させるための強力な磁場（偏極コイル）と、微小なFID信号を拾う受信回路を物理的に切り替えるテストを行いました。
画像のように、M5StackのGroveポートからリレーユニットに接続し、画面上に現在のステータス（「2. Receiving...」「Relay: ON (Listen)」など）を緑色のテキストで表示させながら動作確認をしています。開発環境はArduino IDEを使用し、M5Unifiedライブラリを用いて記述しました。
#### テスト用プログラム（Arduino IDE）
EFNMRのサイクルである「分極（数秒間）」と「受信（FID信号の観測）」を自動で繰り返す、基礎的なステータスマシンのコードです。
```python
#include <M5Unified.h>

// リレーを接続しているGroveポートのピン番号を指定
// ※CoreS3のPort B (I/O) など、実際の接続に合わせて変更してください
const int RELAY_PIN = 8; 

void setup() {
  auto cfg = M5.config();
  M5.begin(cfg);
  
  // リレーのピンを出力モードに設定
  pinMode(RELAY_PIN, OUTPUT);
  
  // 画面のテキスト設定（写真に合わせた緑色）
  M5.Display.setTextSize(2);
  M5.Display.setTextColor(GREEN, BLACK);
}

void loop() {
  // --- 1. 分極フェーズ (Polarization) ---
  // コイルに大電流を流し、プロトンのスピンを地球磁場と直交する向きに揃える
  digitalWrite(RELAY_PIN, LOW); // リレーOFF
  M5.Display.clear();
  M5.Display.setCursor(20, 60);
  M5.Display.println("1. Polarizing...");
  M5.Display.setCursor(20, 90);
  M5.Display.println("Relay: OFF (Charge)");
  
  delay(5000); // 5秒間分極させる

  // --- 2. 受信フェーズ (Receiving) ---
  // コイルからの電流を遮断し、オペアンプ（受信回路）側に切り替えてFID信号を待つ
  digitalWrite(RELAY_PIN, HIGH); // リレーON
  M5.Display.clear();
  M5.Display.setCursor(20, 60);
  M5.Display.println("2. Receiving...");
  M5.Display.setCursor(20, 90);
  M5.Display.println("Relay: ON (Listen)");
  
  delay(3000); // 3秒間信号を受信・計測する
}
```
