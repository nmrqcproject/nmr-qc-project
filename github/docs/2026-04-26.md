### HDL
<br>FPGA←全ての回路が常に動く（代わりにカウンターで時間経過を作る←Hz）
<br>HDL(Hardware Description Language)：ハードウェア記述言語←回路の構造を書く言語,今回使うのはVerilogHDL←C言語に似てる,最も使われている
<br>RTL(Register Transfer Level)：Verilogのコードの書き方
<br>分周器：カウンタの仕組みそのもの,クロックを分割してより遅いクロックを作ること
<br>ステートマシン(FSM)（有限状態機械）：今の状態を覚えて何かが起きたら次の状態に移る仕組み,順番を作る勇逸の方法
<br>NCO（数値制御発振器）：角度を計算する,例→360°=16bit
<br>DDS（直接デジタル合成）：NCOの数字を電圧の波に変換
<br>モジュール
```HDL
module my_chip(
 input clk, //クロック
 input rst_n, //リセットボタン
 output led
);
endmodule
```
<br>信号
```HDL
wrie //針金
reg //箱(レジスタ),値を記録
```
<br>代入
```HDL
assign a = b;: //常に連動
a <= b;: //クロック時にbの値をaにコピー
```
<br>リセットの重要性：FPGAは電源を入れた直後の回路は出鱈目の値→必ずif(!rst_n)
