### ノイズを混ぜる

#### やったこと

ノイズ:宇宙からの雑音や電子回路の雑音

```python
#ノイズの追加
noise = np.random.normal(0, 0.2, len(t)) #平均:0,標準偏差:0.2のホワイトノイズ、テータの数（時間軸と同じ）
noisy_signal = signal + noise #元の信号とノイズを足す
#ノイズ入り信号のグラフ化
plt.figure(figsize=(10,4))
plt.plot(t[:500], noisy_signal[:500])
plt.title("Noisy NMR Signal (Reality)")
plt.xlabel("Time[s]")/plt.ylabel("Amplitude")
plt.grid(True)
plt.show()
#グラフを上下に並べる（サブプロット）※ノイズ入り信号のグラフ化の代わりに入れる
plt.figure(figsize=(10,8))
plt.subplot(2,1,1) #行,列,何番目のグラフか
plt.plot(t[:500], signal[:500], color="blue")
plt.ylabel("Amplitude")
plt.grid(True)
plt.subplot(2,1,2)
plt.plot(t[:500], noisy_signal[:500], color="red")
plt.xlabel("Time[s]")/plt.ylabel("Amplitude")
plt.grid(True)
plt.tight_layout() #グラフが重ならないよう調整
plt.show()
#グラフを重ねて表示
plt.figure(figsize=(10,4))
plt.plot(t[:500], signal[:500], label="Ideal", linewidth=2) #linewidth:線の太さ（デフォルト:1）
plt.plot(t[:500], noisy_signal[:500], label="Noisy", alpha=0.7) #alpha:線の透明度
plt.legend() #凡例を表示
plt.xlabel("Time[s]")/plt.ylabel("Amplitude")
plt.grid(True)
plt.show()
```
