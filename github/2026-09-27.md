### M5StackによるMOSFETとリレーの統合制御（シーケンス構築）

個別にテストを完了した「分極用のMOSFET駆動回路」と「受信用のオペアンプ回路」を切り替えて運用するため、「M5Stack CoreS3 Lite」を用いたシーケンス制御プログラムを実装した。

#### 制御の目的と課題
EFNMRシステムでは、以下の順序で正確に回路を切り替える必要がある。
1. **分極フェーズ**: 受信回路を完全に切り離し、コイルに大電流を流す。
2. **切り替え（サージ保護）フェーズ**: 電流を遮断し、コイルの逆起電力が減衰するのを数ミリ秒待つ。
3. **受信フェーズ**: 微小なFID信号を拾うため、コイルとオペアンプを接続する。

もし分極中の大電流やサージ電圧が残っている状態で受信回路を繋いでしまうと、超低歪オペアンプが瞬時に破壊される。これを防ぐため、「M5Stack用ミニリレーユニット」による物理的な絶縁と、プログラム上のディレイ（デッドタイム）を組み合わせた制御ロジックを構築した。

#### 制御プログラム (Arduino IDE)

「NchパワーMOSFET 2SK4017(Q)」のゲート電圧と、リレーユニットの切り替えを連動させるステートマシンのコード。

```cpp
#include <M5Unified.h>

// ピン設定 (※実際のGroveポートやI/Oに合わせて変更すること)
const int MOSFET_PIN = 8; // MOSFETゲート制御用 (大電流ON/OFF)
const int RELAY_PIN = 9;  // ミニリレーユニット制御用 (受信回路の接続/切断)

void setup() {
  auto cfg = M5.config();
  M5.begin(cfg);
  
  pinMode(MOSFET_PIN, OUTPUT);
  pinMode(RELAY_PIN, OUTPUT);
  
  // 初期状態はどちらもOFF (安全第一)
  digitalWrite(MOSFET_PIN, LOW);
  digitalWrite(RELAY_PIN, LOW);
  
  M5.Display.setTextSize(2);
  M5.Display.setTextColor(GREEN, BLACK);
  M5.Display.println("EFNMR Control Ready");
}

void loop() {
  // ==========================================
  // 1. 分極フェーズ (Polarization)
  // ==========================================
  // 受信回路(オペアンプ)をリレーで物理的に切り離す
  digitalWrite(RELAY_PIN, LOW);
  delay(20); // リレーの機械的な接点が完全に離れるのを待つ
  
  // MOSFETをONにしてコイルに大電流を流す
  digitalWrite(MOSFET_PIN, HIGH);
  M5.Display.clear();
  M5.Display.setCursor(10, 40);
  M5.Display.println("1. Polarizing...");
  delay(5000); // 5秒間分極させる

  // ==========================================
  // 2. サージ減衰フェーズ (Dead Time) ★超重要★
  // ==========================================
  // MOSFETをOFFにして電流を遮断
  digitalWrite(MOSFET_PIN, LOW);
  M5.Display.clear();
  M5.Display.setCursor(10, 40);
  M5.Display.println("2. Surge Waiting...");
  // コイルの逆起電力が還流ダイオードを通じて消滅するのを待機
  // ※このディレイがないと受信回路が破壊される危険がある
  delay(50); 

  // ==========================================
  // 3. 受信フェーズ (Receiving / FID)
  // ==========================================
  // サージが消えた後、受信回路をリレーで接続する
  digitalWrite(RELAY_PIN, HIGH);
  M5.Display.clear();
  M5.Display.setCursor(10, 40);
  M5.Display.println("3. Receiving (FID)");
  
  delay(3000); // 3秒間、PC側(サウンドカード)でFID信号を観測・記録する
}
```
