# 【ブレイクスルー】ついにEFNMRのFID信号観測に成功！ / Breakthrough: Successfully observed EFNMR FID signal! 🎉

ついに、自作のEFNMR（地磁気核磁気共鳴）装置における最大の山場である**「FID（自由誘導減衰）信号」のリアルタイム観測に成功しました！

## 成果の概要
分極コイルの電流をオフにした直後、プロトン（水素原子核）が地磁気の周りを歳差運動しながら元の状態に戻っていく際に出す極めて微弱な信号（FID）を捉えることができました。
しかし、デットタイムの影響でFIDの頭の信号が大きい部分のデータが取れていないため、FFTの山が小さくなってしまっています。

以下の画像と動画は、その決定的な瞬間の記録です。

*   **時間領域（上段）:** マイナス側から滑らかに0に近づいている部分がデットタイムです
*   **周波数領域（下段）:** FFTアナライザにおいて、日本の地磁気におけるプロトンのラーモア周波数に合致する**2.04kHz**付近に、ピークが出現。

## 今後の課題
信号自体は観測できましたが、現状ではまだまだデットタイムや環境ノイズ（ハムノイズやスイッチングノイズ）の影響を大きく受けています。
今後は「ゼロからイチ」を作るフェーズから、システム全体の純度を高める「チューニングフェーズ」へ移行します。

*   **ノイズ対策の実装:** ブレッドボードからユニバーサル基板への移行、アルミケースによるシールド化、BNCケーブルへの置き換えによる信号線の保護。
*   **フィルタ回路の強化:** メタライズドポリエステルフィルムコンデンサを用いたハイパスフィルタにより、低周波ノイズを徹底的にカット。

まずは第一目標を達成しました。量子コンピュータ開発に向けた基盤作りの第一歩です。
引き続き、ノイズフロアを下げてよりクリアな正弦波を引き出すためのチューニングを進めていきます！

###以下は今回のpythonコード
```python
import pyaudio
import numpy as np
import matplotlib.pyplot as plt

# --- 設定 ---
CHUNK = 4096            # 1度に読み込むデータ量（周波数分解能に影響）
RATE = 96000
# サンプリングレート（標準的な48kHz）
FORMAT = pyaudio.paInt16 # 16bitフォーマット
CHANNELS = 1            # モノラル

# PyAudioの初期化
p = pyaudio.PyAudio()
stream = p.open(format=FORMAT,
                channels=CHANNELS,
                rate=RATE,
                input=True,
                frames_per_buffer=CHUNK)

# Matplotlibのグラフ設定
plt.ion() # インタラクティブモードON（リアルタイム描画用）
# 2行1列でグラフを作成し、サイズを少し縦長に調整
fig, (ax_wave, ax_fft) = plt.subplots(2, 1, figsize=(10, 8))

# --- 1. 時間領域（波形）グラフの設定 ---
# X軸を時間（ミリ秒）に換算
x_time = np.arange(0, CHUNK) / RATE * 1000 
line_wave, = ax_wave.plot(x_time, np.zeros(CHUNK))
ax_wave.set_title("Real-time Audio Waveform")
ax_wave.set_xlabel("Time (ms)")
ax_wave.set_ylabel("Amplitude (16bit)")
ax_wave.set_xlim(0, CHUNK / RATE * 1000)
ax_wave.set_ylim(- 5000,  5000) # int16の最大・最小値
ax_wave.grid(True)

# --- 2. 周波数領域（FFT）グラフの設定 ---
x_freq = np.fft.rfftfreq(CHUNK, 1.0 / RATE) # X軸（周波数）の計算
line_fft, = ax_fft.plot(x_freq, np.zeros(len(x_freq)))
ax_fft.set_title("EFNMR Real-time FFT Analyzer")
ax_fft.set_xlabel("Frequency (Hz)")
ax_fft.set_ylabel("Amplitude")
ax_fft.set_xlim(0, 5000) # 観測したい帯域（0Hz 〜 5kHz）に絞る
ax_fft.set_ylim(0, 50)  # Y軸の最大値（信号の大きさによって調整してください）
ax_fft.grid(True)

# グラフ同士が重ならないようにレイアウトを自動調整
plt.tight_layout()

print("観測を開始します。終了する場合はグラフのウィンドウを閉じるか、Ctrl+Cを押してください。")

try:
    while True:
        # 音声データの読み込み
        data = stream.read(CHUNK, exception_on_overflow=False)
        audio_data = np.frombuffer(data, dtype=np.int16)
        
        # 波形グラフの更新
        line_wave.set_ydata(audio_data)
        
        # ハニングウィンドウをかけてノイズを減らす（FFTの定石）
        window = np.hanning(len(audio_data))
        
        # FFTの計算
        fft_data = np.abs(np.fft.rfft(audio_data * window)) / (CHUNK / 2)
        
        # FFTグラフの更新
        line_fft.set_ydata(fft_data)
        
        # 描画の更新
        fig.canvas.draw()
        fig.canvas.flush_events()

except KeyboardInterrupt:
    print("観測を終了します。")

finally:
    # 終了処理
    stream.stop_stream()
    stream.close()
    p.terminate()

```
