### システム統合テスト、痛恨のショートと信号入力の確認

自作した1600回巻きのセンサーコイル、MOSFET駆動回路、そしてオペアンプ受信回路をアルミケース内で物理的に結合し、PCへ信号を取り込むシステム全体の統合テストを実施した。しかし、ハードウェアの洗礼とも言える複数のトラブルに見舞われた。

#### 1. 初歩的なミスとオペアンプの焼損
回路をすべて繋ぎ、StarTech USB接続外付けサウンドカード経由でPCに信号を送るテストを行ったが、全く信号が入ってこなかった。配線やマイクの権限設定を何度も見直した結果、原因はオペアンプを駆動する「9V角形 Panasonicアルカリ乾電池」の残量切れという初歩的なミスだった。
    
急遽新しい電池を買いに行き、焦って配線を繋ぎ直した瞬間に痛恨のミスが発生した。極性を誤って接続してしまい、超低歪低雑音オペアンプ（AD797BRZ）から煙が上がり、ショートさせてしまった。
- （※ここに、煙が出た瞬間の焦りや、予備のオペアンプへの交換・復旧作業など、現場のリアルな所感を1〜2行追記してください）

#### 2. 信号の検知とPython連携の課題
気を取り直して回路を復旧し、再度システムを稼働させたところ、ついにOS側でマイクからの信号入力（通電に伴う何らかの波形）を検知することに成功した。
しかし、リアルタイムでFFT解析を行うために作成した以下のPythonスクリプト（`efnmr_moitor.py`）のグラフには、波形が一切反映されなかった。

```python
import queue
import sys
import numpy as np
import sounddevice as sd
import matplotlib.pyplot as plt
import matplotlib.animation as animation

SAMPLERATE = 48000
CHUNK = 4096
q = queue.Queue()

def audio_callback(indata, frames, time, status):
    if status:
        print(status, file=sys.stderr)
    q.put(indata[:, 0])

fig, (ax1, ax2) = plt.subplots(2, 1, figsize=(10, 6))

x_time = np.arange(0, CHUNK) / SAMPLERATE
line_time, = ax1.plot(x_time, np.zeros(CHUNK), color='blue')
ax1.set_ylim(-1.0, 1.0)
ax1.set_title("Waveform (Time Domain)")

x_freq = np.fft.rfftfreq(CHUNK, d=1/SAMPLERATE)
line_freq, = ax2.plot(x_freq, np.zeros(len(x_freq)), color='red')
ax2.set_xlim(1500, 2500)
ax2.set_ylim(0, 10)
ax2.set_title("FFT - Target 2kHz Peak")

plt.tight_layout()

def update_plot(frame):
    data = None 
    while True:
        try:
            data = q.get_nowait()
        except queue.Empty:
            break
    if data is None:
        return line_time, line_freq
            
    line_time.set_ydata(data)
    
    fft_data = np.abs(np.fft.rfft(data))
    line_freq.set_ydata(fft_data)
    
    max_fft = np.max(fft_data)
    if max_fft > 0:
        ax2.set_ylim(0, max_fft * 1.2)
        
    return line_time, line_freq

try:
    # 課題: device=1 がUSBサウンドカードを正しく指していない可能性が高い
    stream = sd.InputStream(device=1, samplerate=SAMPLERATE, channels=1, callback=audio_callback)
    ani = animation.FuncAnimation(fig, update_plot, interval=50, blit=True, cache_frame_data=False)
    with stream:
        plt.show()
except Exception as e:
    print(f"エラーが発生しました: {e}")
```
