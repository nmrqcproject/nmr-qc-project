### USBサウンドカードを用いた信号取り込みとFFT解析テスト
EFNMRの受信回路で増幅したアナログ信号をPCに取り込み、Pythonで周波数成分を正しく解析（FFT）できるかを検証した。
#### 目的とハードウェア構成
自作の受信コイルで拾った微小なアナログ信号は、PCでデジタル処理するためにADC（A/Dコンバータ）を通す必要がある。今回は、高解像度なサンプリングを行うため「96KHz / 24-bit Hi-Fi USB接続外付けサウンドカード」 を採用した。
アナログ回路からの出力は「汎用シールドBNCケーブル」 を通し、「BNCプラグ → 3.5mmモノラルプラグ 変換アダプタ」 を用いてサウンドカードのマイク入力（またはライン入力）へ接続する構成とした。
#### 実験結果
サウンドカードから入力された音声波形をPythonで読み込み、NumPyの高速フーリエ変換（FFT）にかけてMatplotlibで描画するスクリプトを作成した。
実行した結果、「EFNMR Real-time FFT Analyzer」としてグラフが正常にプロットされ、PC側で周波数（Frequency）ごとの振幅（Amplitude）を解析できるシステムが機能していることを確認した。現在は環境ノイズと思われる低周波帯のピークなどが可視化されており、信号の取り込み自体は成功している。
#### 検証用Pythonコード（リアルタイムFFT解析）
音声入力ライブラリである PyAudio を用いてサウンドカードからのデータストリームを取得し、一定間隔でFFTを計算してプロットする基礎コード。
```python
import pyaudio
import numpy as np
import matplotlib.pyplot as plt

# サウンドカードの仕様に合わせた定数設定
CHUNK = 4096            # 1回に読み込むデータ数
FORMAT = pyaudio.paInt16 # 16-bit または 24-bit (環境に合わせて変更)
CHANNELS = 1            # モノラル入力
RATE = 96000            # サンプリングレート(96kHz)

# PyAudioの初期化
p = pyaudio.PyAudio()

# マイク（サウンドカード）入力ストリームを開く
stream = p.open(format=FORMAT,
                channels=CHANNELS,
                rate=RATE,
                input=True,
                frames_per_buffer=CHUNK)

# グラフの初期設定
plt.ion() # インタラクティブモード（リアルタイム描画）をオン
fig, ax = plt.subplots(figsize=(10, 6))
x_freq = np.fft.rfftfreq(CHUNK, 1.0 / RATE)
line, = ax.plot(x_freq, np.zeros(len(x_freq)))

ax.set_title("EFNMR Real-time FFT Analyzer")
ax.set_xlabel("Frequency (Hz)")
ax.set_ylabel("Amplitude")
ax.set_xlim(0, 5000) # 観測したい周波数帯域 (今回は0〜5000Hz)
ax.set_ylim(0, 50)   # 振幅の表示範囲
ax.grid(True)

print("Listening... (Press Ctrl+C to stop)")

try:
    while True:
        # 音声データの読み込み
        data = stream.read(CHUNK, exception_on_overflow=False)
        # バイナリデータをNumPy配列(整数)に変換
        audio_data = np.frombuffer(data, dtype=np.int16)
        
        # FFT（高速フーリエ変換）の実行
        # 窓関数（ハミング窓）をかけて両端のノイズを減らす
        window = np.hamming(CHUNK)
        fft_data = np.abs(np.fft.rfft(audio_data * window))
        
        # 振幅のスケール調整（見やすくするため）
        fft_data = fft_data / (CHUNK / 2)
        
        # グラフのデータを更新
        line.set_ydata(fft_data)
        fig.canvas.draw()
        fig.canvas.flush_events()

except KeyboardInterrupt:
    print("Stopped by user.")

finally:
    # 終了処理
    stream.stop_stream()
    stream.close()
    p.terminate()
    plt.close()

```
